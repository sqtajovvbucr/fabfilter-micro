## Overview

FabFilter Micro is a compact, easy-to-use synthesizer built around the acclaimed FabFilter filter engine, with a single oscillator, LFO, envelope, and the iconic Volcano filter for hands-on sound design.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **FabFilter Micro** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **FabFilter Filter** | The acclaimed resonant FabFilter filter with 8 modes and overdrive |
| **Simple Oscillator** | Saw, square, and triangle oscillator with detune and sub |
| **One Envelope** | Single ADSR envelope assignable to filter cutoff and volume |
| **One LFO** | Syncable LFO with six shapes routing to cutoff, pitch, or volume |
